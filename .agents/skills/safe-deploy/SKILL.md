---
name: safe-deploy
description: Pre-deploy checklist to validate build, broken links, placeholder text, and responsive layout before publishing.
---
Before committing or deploying website changes:
1. Search the codebase for leftover placeholder text, draft warnings, or outdated dates.
2. Verify all external links (WhatsApp group, checkout, social links) and local asset paths exist.
3. Run the project build command and confirm zero errors or broken imports.
